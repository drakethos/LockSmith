# Changelog

## 0.2.0

- First public cut: chests **and** doors/gates public/private via one craftable Locksmith key.
- Equip key → **E** toggles; unequip to use the piece normally.
- Persists `locksmith_public` on the piece ZDO and mirrors `m_checkGuardStone` on the placed instance.
- Synced config: `EnableChests`, `EnableDoors`, key recipe / station, feature flags (DrakeModsLibs).
- Play-tested on Gale `drakeTest` (chest + wood/darkwood gate toggles).
- Roadmap called out in README (piece mode, RenameIt soft hooks, optional per-person / physical-key modes later).
